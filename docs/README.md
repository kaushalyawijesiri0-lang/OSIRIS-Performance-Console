# Documentation

This directory contains the technical documentation and final project report for **OSIRIS – Integrated Performance Console**, developed as part of IN1901: Microcontroller Based Application Development at the University of Moratuwa.

## Available Documentation

### Final Project Report

The final project report provides a comprehensive description of the OSIRIS system, including its objectives, system architecture, hardware and software implementation, components, testing procedures, results, and project budget.

**Document:** [OSIRIS Final Project Report](OSIRIS_Final_Project_Report.pdf)

## Documentation Scope

The documentation covers the following areas:

- Project introduction and objectives
- System architecture and design
- Hardware components and circuit implementation
- Software implementation and functionality
- Integration and testing
- Results and evaluation
- Project budget and cost analysis

## Related Documentation

For additional hardware-specific information, including component lists, circuit schematics, and PCB design references, refer to the [`hardware`](../hardware/) directory.
